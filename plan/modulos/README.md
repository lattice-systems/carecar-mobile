# Catálogo de módulos de CareCar v2

M01–M03 son los módulos de la **ficha técnica** (obligatorios, intocables en su alcance). Del M04 en adelante son módulos nuevos propuestos para la v2. T01–T05 son frentes técnicos que sostienen a todos.

Cada módulo tiene su archivo con propósito, pantallas, datos, API e historias (`V2-Mxx.nn`). Plantilla: [`_plantilla.md`](_plantilla.md).
